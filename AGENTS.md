KM Calc is a plain React Native (CLI, no Expo) app in TypeScript — Android first, iOS from the same code — that tracks the km left on a rental car and the cost of extra km. Every change must keep working on Android and iOS.

## Commands

```bash
npm start            # Metro dev server
npm run android      # debug build on the running emulator / connected phone (needs ANDROID_HOME and JAVA_HOME)
npm run check        # typecheck + lint + tests: run before declaring any task done
cd android && ./gradlew assembleRelease   # release APK (signed when KMCALC_* Gradle properties are set)
```

Check a library's compatibility with the React Native version in `package.json` before adding it; after adding one with native code, rebuild the app (`npm run android`), a Metro reload is not enough.

## Project structure

- `App.tsx` — providers, saved data and switching between the two screens (no navigation library: one main screen and a defaults screen).
- `src/logic/` — pure calculation code (`calc.ts`, `dates.ts`, `numbers.ts`) with unit tests. Keep UI code out of here.
- `src/state/` — the rental form, the default values and AsyncStorage persistence. Saved data is validated when loaded (`normalizeRental`, `normalizeDefaults`); keep that working when adding fields.
- `src/screens/`, `src/components/` — UI. Styles come from `useThemedStyles(makeStyles)` so light and dark themes both work. Icons are tinted PNGs (`src/components/Icon.tsx`, generated by `scripts/generate-ui-icons.js`).
- `__tests__/App.test.tsx` — UI tests with React Native Testing Library (v14: `render`, `fireEvent` and friends are async and must be awaited).
- `android/`, `ios/` — native projects, committed and edited directly. App name, version, signing and launcher icons live there.

## Rules

- Dates are `YYYY-MM-DD` strings handled by `src/logic/dates.ts`; never do day arithmetic with `Date` objects directly.
- Numeric inputs are stored as the typed text and parsed with `parseNumber`, so Arabic-Indic digits and decimal commas keep working.
- The release app has no permissions; `INTERNET` is only added for debug builds (`android/app/src/debug/AndroidManifest.xml`).
- Releases: bump `versionCode`/`versionName` in `android/app/build.gradle` (plus `package.json` and the iOS versions), then push a `v*` tag. Never commit signing keys.
